# Avalonia 标定数据表格编辑控件需求 v3

## 概述

开发一组基于 Avalonia UI 框架 V12 的标定数据表格编辑控件，用于汽车 ECU 标定工具中的曲线和 Map 数据编辑。控件组包含 **3 个独立控件**，分别支持 1 维（曲线）、2 维（Map）和 3 维数据的显示与编辑，并配合图表可视化。

每个控件均采用统一的**顶部信息栏 + 主内容区**布局模式，支持通过变量选择下拉框在多个标定变量之间快速切换。

## 公共架构

### 顶部信息栏

所有 3 个控件均包含一致的顶部信息栏：

- **左侧**：变量选择下拉框（`ComboBox`）
  - 控件接收 `List<T>` 形式的数据源（`T` 为对应维度的标定数据模型）
  - 列表中的每个数据项作为下拉框的一个选项
  - 下拉框显示项的文本由数据模型的名称属性决定（如变量名及所属变量组，格式如 `<曲线变量组> AllMkn_n_AirMax`）
  - 选中下拉框选项后，主内容区切换展示对应的标定数据
- **右侧**：当前变量的单位信息以及各轴变量名和单位（如 `[mgpl] x: AllMkn_n_AirMax [rpm]`）

### 数据模型接口

每个控件需定义对应的数据模型接口（或泛型约束），至少包含：

- 变量名称（用于下拉框显示）
- 变量单位
- 各轴变量名及单位
- 数据值集合
- 数据变更通知机制（支持 Avalonia `INotifyPropertyChanged`）

## 1 维控件：曲线编辑器（CurveEditor）

适用于一维标定数据（曲线），参考图 1。

### 布局

上方为折线图区域，下方为可编辑的 1 维数据表格。

### 折线图

- 显示 x-z 数据关系的折线图
- x 轴和 z 轴均显示变量名及单位作为轴标签
- 数据点以方块标记，点与点之间以直线连接
- 支持数值读取和可视化（至少支持静态展示；是否支持交互式缩放/平移由设计阶段确定）

### 数据表格

- 以两行形式展示：第一行为 x 轴（自变量）值，第二行为 z 轴（因变量）值
- x 行与 z 行一一对应
- 所有单元格支持直接数值编辑
- 当前编辑或选中的单元格需有高亮标识（与 2 维表格的选中高亮保持一致）

## 2 维控件：Map 编辑器（MapEditor）

适用于二维标定数据（Map/曲面），参考图 2。

### 布局

左侧为 3D 曲面预览图，右侧为可编辑的 2 维数据表格。

### 3D 曲面图

- 显示数据的立体分布情况，具有 x、y、z 三个坐标轴
- 曲面以彩色网格形式呈现
- 至少支持默认视角展示；基于标定工具的使用场景，支持旋转或视角调整是合理的交互预期

### 数据表格

- 表头格式为 `y \ x`
- x 轴值作为列头显示在表格顶部
- y 轴值作为行头显示在表格左侧
- 单元格中显示对应 (x, y) 位置的 z 值
- 当前选中或正在编辑的单元格以蓝色背景高亮显示
- 所有单元格支持直接数值编辑

## 3 维控件：数据立方体编辑器（CubeEditor）

适用于三维标定数据。

### 布局（v3 重新设计）

主内容区从左到右分为两个区域：

1. **左侧**：3D 曲面预览图——展示当前"激活/聚焦"z 切片对应的 2 维 (x, y) → value 数据的立体分布
2. **右侧**：数据表格——以平铺形式展示完整的 3 维数据，表格行头同时包含 z 轴和 y 轴信息

### 数据表格

表格采用 **(z, y) 双列行头 + x 轴列头** 的结构，将 3 维数据立方体在 2 维平面中完整展开：

- **行头第一列（z 轴列）**：展示每个数据行对应的 z 轴值
  - 位于 y 轴列的左侧，与 y 轴列宽度、字体样式保持一致
  - 相同 z 值的连续行在 z 列中采用**合并单元格**形式展示，视觉上形成一个 z 切片分组
  - 合并后的 z 单元格垂直居中显示该 z 值
- **行头第二列（y 轴列）**：展示每个数据行对应的 y 轴值，与 `MapEditor` 的行头一致
- **列头（x 轴）**：展示 x 轴值，与 `MapEditor` 的列头一致
- **数据单元格**：展示对应 (x, y, z) 位置的数据值
- 表格按 z 轴值分组排序，每组内部按 y 轴值排序，形成清晰的多层切片结构

**z 切片激活与 3D 视图联动**：

- 表格中当前**激活/聚焦**的 z 切片决定了左侧 3D 曲面图展示的数据
- 激活 z 切片通过以下方式确定：
  - 用户点击（或键盘导航至）表格中某个单元格时，该单元格所属行的 z 值即为激活 z 切片
  - 若 z 列采用合并单元格，点击合并的 z 单元格可直接将该 z 值设为激活切片，同时选中该切片内的第一个数据单元格
- 当激活 z 切片变化时，左侧 3D 曲面图同步刷新，展示该 z 切片对应的 (x, y) → value 数据

**单元格编辑**：

- 所有数据单元格支持直接数值编辑
- z 轴列和 y 轴列作为行头标识，原则上**不可编辑**（其值由标定数据模型决定，非用户输入值）
- 若业务场景需要支持 z 轴和 y 轴的数值编辑，需在实现阶段通过数据模型约束控制

### 3D 曲面图

- 展示当前激活 z 切片对应的 (x, y) → value 数据的立体分布
- 具有 x、y、value 三个坐标轴
- 曲面以彩色网格形式呈现
- 当激活 z 切片切换时，3D 曲面图同步更新
- 至少支持默认视角展示；支持旋转或视角调整是合理的交互预期

## 公共交互与功能

以下功能适用于所有 3 个控件：

### 单元格编辑

- 表格单元格支持直接数值编辑。具体触发方式（单击进入编辑或双击进入编辑）以及键盘导航（方向键移动、Tab 切换、Enter 确认等）由设计阶段确定
- 输入的数据应能正确解析为数值类型

### 选中高亮

- **单元格级高亮**：当前活动单元格（选中或编辑中）需有视觉高亮标识，2 维表格中表现为蓝色背景，1 维和 3 维表格沿用一致的视觉风格
- **行级高亮（CubeEditor 新增）**：当前选中单元格所在的整行可附加轻微的背景色高亮，辅助用户在跨列浏览时定位当前行
- **z 切片级高亮（CubeEditor 新增）**：当前激活的 z 切片在表格中所有属于该切片的行附加统一的视觉标识（如左侧边框高亮或分组背景色），明确指示左侧 3D 曲面图当前展示的是哪一组数据
- z 列和 y 列的行头文字在激活状态下可采用加粗或颜色变化作为辅助标识

### 数据绑定

- 控件应支持 Avalonia 的数据绑定机制，便于与后端标定数据模型对接
- 数据变更应能正确反映到 UI，UI 编辑也应能同步回数据模型
- `List` 形式的数据源绑定到变量选择下拉框，选中项变更时主内容区自动刷新

### 隐含但必要的功能

- 基于标定数据的特点，需考虑数值精度和小数位数的一致性展示
- 表格应支持列宽/行高的自适应或手动调整，以保证不同数据量下的可读性
- 数据编辑后应有适当的变更反馈机制（设计阶段确定具体形式，如即时同步、显式保存等）

---

## 技术约束

- 基于 **Avalonia UI 框架 V12 版本** 开发
- 作为可复用的 UI 控件封装，支持嵌入到更大的标定工具界面中
- 3 个控件为独立实现，但在视觉风格、交互逻辑和数据绑定模式上保持一致

---

## 范围边界

### 在范围内

- 1 维、2 维、3 维标定数据的表格展示与编辑
- 1 维折线图、2 维/3 维 3D 曲面图的数据可视化
- 顶部变量选择器（List 数据源 → 下拉框）与单位信息展示栏
- 数据绑定接口

### 不在范围内（除非用户后续明确补充）

- 标定数据的后端存储与读写（控件只负责展示和编辑，不直接处理文件 I/O）
- 多变量对比、差分显示等高级分析功能
- 撤销/重做（undo/redo）系统——虽然对编辑工具很重要，但用户原始需求中未提及，暂不纳入
- 复制/粘贴、批量填充等批量编辑操作——用户原始需求中未提及，暂不纳入

## 推断与待确认事项

| 事项 | 说明 |
|------|------|
| 图表交互深度 | 折线图和 3D 曲面图是否支持缩放、平移、旋转等交互操作，用户未明确说明，基于标定工具场景推测至少需要默认视角展示，进一步交互由设计阶段决定 |
| 数据类型与验证 | 标定数据通常为浮点数，但用户未明确数据类型、精度、取值范围及非法输入的处理策略，由设计阶段基于标定数据通用特点确定 |
| 编辑触发方式 | 单元格是单击直接编辑还是双击编辑，由设计阶段结合 Avalonia V12 的标准交互模式确定 |
| 3D 曲面图数据源切换动画 | `CubeEditor` 切换激活 z 切片时，3D 曲面图是直接刷新还是有过渡动画，由设计阶段确定 |
| z 列合并单元格实现方式 | z 列相同值的合并展示可通过 Avalonia `DataGrid` 的跨行单元格实现，或采用重复值 + 视觉分组线方案；具体实现策略由设计阶段基于 Avalonia V12 控件能力评估确定 |
| 长表格滚动性能与用户体验 | 当 z 切片数量多且 y 维度大时，表格行数可能显著增加（z 数 × y 数），是否需要引入虚拟化滚动、z 切片折叠/展开或分页机制，由设计阶段评估确定 |
| z/y 行头是否可编辑 | 当前设计将 z 列和 y 列定位为行头标识而不可编辑；若标定业务允许直接修改轴点值，需在实现阶段开放编辑并增加数据校验 |
| z 切片级高亮视觉方案 | 当前需求提出左侧边框或分组背景色的概念，具体颜色、粗细、动画等视觉参数由设计阶段确定，需确保与单元格级蓝色高亮可区分且不冲突 |
| 键盘跨 z 切片导航行为 | 用户在表格中使用方向键从当前 z 切片的最后一行 y 值移入下一 z 切片的第一行 y 值时，3D 曲面图是否即时切换；若数据量大，是否需要防抖或延迟切换机制，由设计阶段确定 |

# Judge 裁决报告 — OOD 设计文档 v8

- **设计方案**：Avalonia 标定数据表格编辑控件 — 架构级 OOD 设计方案 v8
- **质量审查报告**：8 项新问题（0 严重 / 3 一般 / 5 轻微），评级 B+
- **质量挑战报告**：确认 7 项有效（排除 1 项），新增 1 项遗漏，全部为非严重级别
- **前 5 轮历史问题**：53 项，已全部在 v8 中修复

---

## 裁决依据

### 1. 历史问题修复确认

经审查，前 5 轮迭代累计 53 项历史问题均已在 v8 设计文档中得到恰当修复。关键修复包括：
- `DataGrid.CurrentCell` 事实错误已全部替换为 Avalonia 实际 API（`SelectedItem` + `CurrentColumn` + `BeginEdit()`）
- 单元格级脏标记已降级为全局未保存提示
- `ActiveZSliceChangedEventArgs` 数组越界已防护
- `IReadOnlyList<TRow>` 与增量刷新矛盾已通过 `ReplaceRow` 解决
- 轴属性已下沉到维度子接口
- 动态列绑定已从索引器改为 `IReadOnlyList<double> Values`

### 2. 本轮问题综合评估

| # | 问题摘要 | 原评级 | 挑战结论 | Judge 意见 |
|---|---------|--------|---------|-----------|
| 1 | `DisplayPrecision = 0` 与后备格式 `G6` 语义矛盾 | 一般 | AGREE | 真实问题，实现阶段应优先处理；建议采纳 `int?` 方案或明确语义声明 |
| 2 | 全量刷新后选中状态恢复存在可靠性风险 | 一般 | AGREE | 真实问题；建议统一使用 `SelectedIndex = rowIndex` 恢复行选中，统一列索引类型 |
| 3 | `DataContextChanged` 事件订阅清理策略缺失 | 一般 | AGREE | 真实问题；建议在 `UnloadingRow` 中补充取消订阅，或移除 `DataContextChanged` 后备机制 |
| 4 | `FormatString` 可空性不一致 | 轻微 | AGREE | 真实问题；建议统一为不可空 `string` 并以空字符串表示"未提供" |
| 5 | `ActiveZSliceChangedEventArgs` 缺少构造函数 | 轻微 | **CHALLENGE** | 接受挑战结论；OOD 层面事件参数类型定义属性即可，构造函数属于实现细节，且审查 Agent 存在选择性审查不一致 |
| 6 | `CalibrationEditorBase<T>` 未提及 `StyleKeyOverride` | 轻微 | **PARTIAL** | 接受挑战结论；属于 Avalonia 框架编码常识，非架构设计缺陷，可选在进入实现阶段时顺手补充 |
| 7 | `CubeEditor` z 列点击选中处理时机歧义 | 轻微 | AGREE | 真实问题；建议明确推荐同步代码即时执行，删除"或"的模糊表述 |
| 8 | 动态列绑定兼容性论述不够精确 | 轻微 | AGREE | 真实问题；建议修正为 Runtime Binding 兼容性论述 |
| — | `ResetToDefault()` 与防抖计时交互未明确（遗漏） | 一般 | 新增 | 真实问题；建议明确 `ResetToDefault()` 应取消正在进行的防抖计时，或规定变量切换时重建 Tracker 实例 |

### 4. 架构质量评估

- **模块划分**：Views 层、数据契约层、表格适配层、图表抽象层、激活追踪层、Curve 表格契约层六层划分清晰，依赖方向正确

- **Avalonia API 使用**：`CurrentCell` 事实错误已彻底消除，`SelectedItem`/`CurrentColumn`/`BeginEdit()` 组合覆盖全部关键路径；`LoadingRow`/`UnloadingRow` 虚拟化策略正确

- **边界条件**：空状态、零维度、数组越界、保存异常、渲染失败、数值解析失败等场景均有明确处理策略
- **性能与可测试性**：`readonly struct` 行数据、增量刷新可选路径、`TimeProvider` 注入、`ZSliceActivationTracker` 独立抽取等设计体现了性能意识和可测试性意识

## 裁决结论

### 最终裁决：PASS

**理由**：

1. **不存在严重问题**：本轮全部有效问题均为"一般"或"轻微"级别，无架构级别缺陷，无阻塞性设计错误。
2. **历史问题全部修复**：前 5 轮 53 项历史问题已得到恰当修复，修复措施合理。
3. **架构设计质量合格**：模块划分、接口契约、依赖方向、交互行为、边界条件处理均达到可进入实现阶段的标准。
4. **实现阶段可消化剩余问题**：剩余的 8 项有效问题（含 1 项遗漏）均为实现层面的语义明确性和接口一致性问题，可在编码过程中逐一澄清和修复，不需要阻塞设计文档定稿。

### 建议（非强制）

以下问题建议在进入实现阶段时优先处理，以消除实现者与控件层之间的理解偏差：

1. **高优先级**：`DisplayPrecision` 语义矛盾（问题 1）、全量刷新选中恢复策略（问题 2）、`ResetToDefault()` 与防抖计时交互（遗漏问题）
2. **中优先级**：`DataContextChanged` 订阅清理（问题 3）、`FormatString` 可空性统一（问题 4）
3. **低优先级**：z 列点击选中时机明确（问题 7）、动态列绑定论述修正（问题 8）、`StyleKeyOverride` 补充（问题 6）

# 任务：设计合规性审查

## 审查目标

检查设计文档 **"Avalonia 标定数据表格编辑控件 — 架构级 OOD 设计方案 v2"** 是否完整满足需求文档 **"Avalonia 标定数据表格编辑控件需求 v3"** 中定义的所有功能性需求、交互需求和技术约束。

- **设计文档**：`C:\Users\jiangwei\Documents\C#\INCA_MAP_Control\docs\2_ood.md`

## 审查范围

设计文档需覆盖需求文档中定义的全部内容：

### 1. 公共架构
- [ ] 顶部信息栏（左侧变量选择 `ComboBox` + 右侧单位/轴信息）
- [ ] 数据模型接口（`ICalibrationData` 及维度特化子接口）
- [ ] `List<T>` 形式数据源绑定

### 2. CurveEditor（1 维控件）
- [ ] 上方折线图 + 下方两行表格（x 行 + z 行）
- [ ] 折线图：x-z 关系、方块标记、直线连接、轴标签
- [ ] 表格：所有单元格可编辑、选中高亮

### 3. MapEditor（2 维控件）
- [ ] 左侧 3D 曲面图 + 右侧 2 维表格
- [ ] 3D 曲面图：x/y/z 三轴、彩色网格、视角旋转
- [ ] 表格：`y \\ x` 表头、x 列头 + y 行头、蓝色选中高亮、所有单元格可编辑

### 4. CubeEditor（3 维控件）
- [ ] 左侧 3D 曲面图（展示当前激活 z 切片）+ 右侧平铺表格
- [ ] 表格：(z, y) 双列行头 + x 列头 + 数据单元格
- [ ] z 列合并单元格展示（或等效视觉分组）
- [ ] z 切片激活机制（点击/键盘导航确定激活切片）
- [ ] 3D 视图与激活切片联动刷新
- [ ] z/y 行头不可编辑，数据单元格可编辑

### 5. 公共交互与功能
- [ ] 单元格编辑（双击进入编辑、数值解析、键盘导航）
- [ ] 选中高亮：单元格级（蓝色）+ 行级（CubeEditor）+ z 切片级（CubeEditor）
- [ ] 数据绑定（双向、变更通知、下拉框切换自动刷新）
- [ ] 数值精度一致性、列宽/行高可调、变更反馈机制

### 6. 技术约束
- [ ] 基于 Avalonia UI V12
- [ ] 可复用 UI 控件封装
- [ ] 3 个控件独立实现但风格一致

### 7. 范围边界
- [ ] 在范围内：表格展示编辑、图表可视化、变量选择、数据绑定接口
- [ ] 不在范围内：后端存储、多变量对比、undo/redo、复制粘贴批量编辑

## 输出要求

审查过程中需识别设计文档中**缺失的需求覆盖**、**与需求不一致的设计决策**、**需求明确但设计未涉及的功能点**，以及**设计决策与需求推断/待确认事项的冲突或偏离**。最终产出一份诊断报告，列明所有发现的问题及其严重程度。

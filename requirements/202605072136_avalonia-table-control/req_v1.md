# Avalonia 标定数据表格编辑控件需求

## 概述

开发一个基于 Avalonia UI 框架的数据表格编辑控件，用于汽车 ECU 标定工具中的曲线和 Map 数据编辑。控件需支持 1 维（曲线）、2 维（Map）和 3 维数据的显示与编辑，并配合图表可视化。

## 控件总体结构

控件采用统一的顶部信息栏 + 主内容区的布局模式：

- **顶部信息栏**：左侧为变量选择下拉框，显示当前变量的名称及所属变量组（如 `<曲线变量组>`、`<Map变量组>`）；右侧显示当前变量的单位信息以及各轴变量名和单位（如 `[mgpl] x: AllMkn_n_AirMax [rpm]`）
- **主内容区**：根据数据维度展示对应的表格和可视化图表

## 1 维表格（曲线编辑器）

适用于一维标定数据（曲线），参考图1。

**布局**：上方为折线图区域，下方为可编辑的 1 维数据表格。

**折线图**：
- 显示 x-z 数据关系的折线图
- x 轴和 z 轴均显示变量名及单位作为轴标签
- 数据点以方块标记，点与点之间以直线连接
- 支持数值读取和可视化（基于现有截图，至少支持静态展示；是否支持交互式缩放/平移由设计阶段确定）

**数据表格**：
- 以两行形式展示：第一行为 x 轴（自变量）值，第二行为 z 轴（因变量）值
- x 行与 z 行一一对应
- 所有单元格支持直接数值编辑
- 当前编辑或选中的单元格需有高亮标识（与 2 维表格的选中高亮保持一致）

## 2 维表格（Map 编辑器）

适用于二维标定数据（Map/曲面），参考图2。

**布局**：左侧为 3D 曲面预览图，右侧为可编辑的 2 维数据表格。

**3D 曲面图**：
- 显示数据的立体分布情况，具有 x、y、z 三个坐标轴
- 曲面以彩色网格形式呈现
- 至少支持默认视角展示；基于标定工具的使用场景，支持旋转或视角调整是合理的交互预期

**数据表格**：
- 表头格式为 `y \ x`
- x 轴值作为列头显示在表格顶部
- y 轴值作为行头显示在表格左侧
- 单元格中显示对应 (x, y) 位置的 z 值
- 当前选中或正在编辑的单元格以蓝色背景高亮显示
- 所有单元格支持直接数值编辑

## 3 维表格

适用于三维标定数据。用户描述其展示方式为：在 2 维表格的基础上，在 y 轴侧边增加一列 z 轴，x 轴仍为列，y 轴为主行，z 轴作为嵌套在 y 下的行维度，单元格中为对应的数据值。

这意味着：对于每个 y 值，其下可嵌套多个 z 子行，每个 z 子行包含 x 列的数据。本质上将 3 维数据 (x, y, z) → value 以嵌套行表格的形式展平为 2 维表格呈现。

该展示方式在实现细节上有一定设计空间（例如：z 子行是始终展开还是可折叠、y 主行是否显示汇总值等），具体交互由设计阶段细化。

## 公共交互与功能

以下功能适用于所有维度的表格：

**单元格编辑**：
- 表格单元格支持直接数值编辑。具体触发方式（单击进入编辑或双击进入编辑）以及键盘导航（方向键移动、Tab 切换、Enter 确认等）由设计阶段确定
- 输入的数据应能正确解析为数值类型

**选中高亮**：
- 当前活动单元格（选中或编辑中）需有视觉高亮标识，2 维表格中表现为蓝色背景，1 维和 3 维表格沿用一致的视觉风格

**数据绑定**：
- 控件应支持 Avalonia 的数据绑定机制，便于与后端标定数据模型对接
- 数据变更应能正确反映到 UI，UI 编辑也应能同步回数据模型

**隐含但必要的功能**（基于表格编辑的通用交互常识推断）：
- 基于标定数据的特点，需考虑数值精度和小数位数的一致性展示
- 表格应支持列宽/行高的自适应或手动调整，以保证不同数据量下的可读性
- 数据编辑后应有适当的变更反馈机制（设计阶段确定具体形式，如即时同步、显式保存等）

## 技术约束

- 基于 **Avalonia UI 框架 V12 版本** 开发
- 作为可复用的 UI 控件封装，支持嵌入到更大的标定工具界面中

## 范围边界

**在范围内**：
- 1 维、2 维、3 维标定数据的表格展示与编辑
- 1 维折线图、2 维 3D 曲面图的数据可视化
- 顶部变量选择器与单位信息展示栏
- 数据绑定接口

**不在范围内**（除非用户后续明确补充）：
- 标定数据的后端存储与读写（控件只负责展示和编辑，不直接处理文件 I/O）
- 多变量对比、差分显示等高级分析功能
- 撤销/重做（undo/redo）系统——虽然对编辑工具很重要，但用户原始需求中未提及，暂不纳入
- 复制/粘贴、批量填充等批量编辑操作——用户原始需求中未提及，暂不纳入

## 推断与待确认事项

| 事项 | 说明 |
|------|------|
| 3D 表格的具体交互 | 用户描述了展示结构，但 y 主行与 z 嵌套子行之间的交互细节（是否可折叠、是否显示汇总行等）需要设计阶段确认 |
| 图表交互深度 | 折线图和 3D 曲面图是否支持缩放、平移、旋转等交互操作，用户未明确说明，基于标定工具场景推测至少需要默认视角展示，进一步交互由设计阶段决定 |
| 数据类型与验证 | 标定数据通常为浮点数，但用户未明确数据类型、精度、取值范围及非法输入的处理策略，由设计阶段基于标定数据通用特点确定 |
| 编辑触发方式 | 单元格是单击直接编辑还是双击编辑，由设计阶段结合 Avalonia V12 的标准交互模式确定 |
| 变量选择器数据源 | 下拉框的选项数据来源和动态更新机制，用户未详细说明，由数据绑定接口的设计定义 |

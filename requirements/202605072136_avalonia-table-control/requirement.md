# 用户原始需求

## 概述

采用 Avalonia V12 版本开发数据表格编辑控件，用于显示和编辑标定数据（类似汽车ECU标定工具中的曲线和Map编辑器）。控件需支持1维、2维和3维表格的显示与编辑。

## 参考截图

### 图1：一维曲线/表格编辑器（Snipaste_2026-05-07_21-12-59.png）

展示一个1D（曲线）数据编辑器界面：
- **顶部区域**：下拉选择框显示变量名称（如 `AllMkt_rho_AirMaxDensComp <曲线变量组>`），右侧显示变量单位信息（如 `[mgpl (milligrams / liter (mg/l))]  x: AllMkn_n_AirMax [rpm (revolutions / minute (rpm))]`）
- **中间图表区域**：折线图显示 x-z 数据关系
  - x轴标签：`AllMkn_n_AirMax [rpm]`
  - z轴标签（y轴方向）：`z: AllLMkt_...`
  - 数据点以方块标记，点与点之间以直线连接
  - 图表支持数值读取和可视化
- **底部表格区域**：可编辑的1维数据表格
  - 第一行（x）：自变量值，如 `600, 725, 850, 1000, 1200, 1400, 1600, 1800, 2000, 2250, 2500, 3000, 3500, 4000, 4500, 5000, 5200, 5700, 5900`
  - 第二行（z）：因变量值，如 `3000, 3000, 3000...`，与x行一一对应
  - 表格单元格可直接编辑修改

### 图2：二维Map编辑器（Snipaste_2026-05-07_21-13-27.png）

展示一个2D（Map/曲面）数据编辑器界面：
- **顶部区域**：下拉选择框显示Map变量名（如 `AllMkt_rho_AirMinAmbPresRng0 <Map变量组>`），右侧显示x轴和y轴的变量名及单位信息
- **左侧3D预览区域**：3D曲面图预览，显示数据的立体分布情况
  - 具有x、y、z三个坐标轴
  - 曲面以彩色网格形式呈现
  - 支持旋转或视角调整（至少展示默认视角）
- **右侧表格区域**：可编辑的2维数据表格
  - 表头：`y \ x`
  - x轴（列头）：`600, 800, 1000, 1500, 2000, 2500, 3000, 4000, 5000, 6000`
  - y轴（行头）：`-40.0, -20.0, 0.0000, 20.00, 50.00, 90.00`
  - 单元格中为z值，如 `400, 370, 365...`
  - 当前选中/编辑的单元格高亮显示（蓝色背景）
  - 表格单元格可直接编辑修改

## 功能要求

1. **1维表格显示**：类似图1，以行形式显示x轴和z轴两行数据，上方配合折线图可视化
2. **2维表格显示**：类似图2，以行列矩阵形式显示x轴（列）、y轴（行）和z值（单元格），左侧配合3D曲面图预览
3. **3维表格显示**：在2维表格的基础上，在y轴侧边增加一列z轴，形成3维数据的展示形式。具体展示方式需支持：x轴为列、y轴为主行、z轴为嵌套的行维度，单元格中为对应的数据值
4. **数据编辑**：所有表格的单元格均应支持直接数值编辑
5. **数据绑定**：控件应支持数据绑定，便于与后端标定数据模型对接
6. **Avalonia V12**：基于Avalonia UI框架V12版本开发
